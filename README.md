
# Statistical Learning Portfolio

A collection of statistical modeling and machine learning reports built with Quarto. Each report explores core predictive modeling techniques, model selection, and validation strategies.

## Interactive Reports

* **[Cross-Validation & Model Resampling](https://sarojbhatta.github.io/statistical-learning/statistical-reports/html-reports/01_cross_validation_portfolio.html)** — Evaluating Polynomial Regression Models on the Auto Dataset. <br>
*Evaluating polynomial regression models for fuel efficiency prediction using validation set and k-fold cross-validation methods on the Auto dataset.*

* **[Regularized Regression: Ridge, Lasso & Elastic Net](https://sarojbhatta.github.io/statistical-learning/statistical-reports/html-reports/02_ridge_lasso_elastic_portfolio.html)** — Regularized Regression for Geographic Music Origin Prediction. <br>
*A comparative analysis of regularized regression methods for predicting geographic origin of music from audio features, with hyperparameter tuning via 10-fold cross-validation.*

* **[Logistic Regression & Classification](https://sarojbhatta.github.io/statistical-learning/statistical-reports/html-reports/03_logistic_regression_portfolio.html)** — Classification Analysis of S&P 500 Daily Returns using the Smarket Dataset. <br>
*Applying logistic regression to classify daily S&P 500 market movements as Up or Down using lagged return and trading volume features from the Smarket dataset.*

* **[Nonlinear Regression Modeling](https://sarojbhatta.github.io/statistical-learning/statistical-reports/html-reports/04_nonlinear_regression_portfolio.html)** — Fitting Natural Splines and Polynomial Models for Age Effects on Wage. <br>
*Fitting natural splines and polynomial regression to model wage as a non-linear function of age, with tuned degrees of freedom and partial dependence visualization using the wage dataset.*

* **[Tree-Based & Ensemble Methods](https://sarojbhatta.github.io/statistical-learning/statistical-reports/html-reports/05_ensemble_methods_portfolio.html)** — Bagging, Random Forests, Gradient Boosting, Elastic Net & Model Stacking on the Carseats Dataset. <br>
*Comparing bagging, random forests, gradient boosting, elastic net, and model stacking for predicting car seat sales from retail and product attributes using the Carseats dataset.*
